# Design Canvas Vault — Complete Design Engineering Guidelines & 200 Website Audits

## PART I — COMPLETE DESIGN ENGINEERING GUIDELINES (01 TO 09)

# 01 — Refactoring UI: Hierarchy, Spacing, Typography, Color, Depth & Components

## 1. Starting From Scratch
- **Feature First, Shell Later**: Never code the outer navbar/sidebar shell first. Build the core functional unit (search form, invoice row, issue card) first; wrap navigation around it once ergonomic.
- **Low-Fidelity & Grayscale First**: Wireframe without color/shadows first to force reliance on **spacing, contrast, weight, and scale**. Add color last to reinforce hierarchy.
- **Work in Narrow Cycles & Stress-Test Content**: Ship the smallest useful version and test worst-case content: 42-char names, 4-line wrapped titles, broken images, 0-row empty states, 1,000-row pagination, and multi-line errors.
- **4 Levers of Personality**:
  1. *Typography*: Geometric Sans (`Geist, Plus Jakarta Sans`) = modern; Monospace (`JetBrains Mono, Geist Mono`) = technical/data; High-contrast Serif (`Playfair, Instrument Serif, Portrait`) = editorial/luxury; Rounded Sans = friendly.
  2. *Color*: Blue = trust/banking; Gold/Espresso = luxury/heritage; Emerald = growth/finance.
  3. *Border Radius*: `0px` = brutalist/industrial/luxury; `4px–8px` = technical SaaS/dev; `12px–24px` = tactile modern; `9999px` (pill) = accessible/consumer.
  4. *Voice*: Formal vs. direct action. Lock all values to predefined scales.

## 2. Hierarchy Is Everything
- **Weight & Contrast Over Size**: Use `font-weight: 500–700` and color contrast instead of inflating font sizes; a `14px` bold high-contrast label beats a `20px` low-contrast title.
- **3-Tier Text Contrast System**:
  ```css
  /* Light Mode */ --text-primary: #0f172a; --text-secondary: #475569; --text-tertiary: #94a3b8;
  /* Dark Mode  */ --text-primary: #f8fafc; --text-secondary: #94a3b8; --text-tertiary: #64748b;
  ```
- **Tint Text on Colored Surfaces**: Never place `#888` gray text on colored backgrounds; tint secondary text using the background hue (e.g., `#93c5fd` or `rgba(255,255,255,0.75)` on `#0b44a7` navy).
- **De-Emphasize Competing Noise**: Soften surrounding elements (dim inactive links to `60%` opacity, replace borders with background shifts) so focal elements pop.
- **Eliminate Naive `Label: Value` Pairs**: Infer from format (`john@domain.com`), merge into value (*"12 left in stock"*), or use status dots (`● Completed`). When labels are needed, set as micro-metadata (`11–12px fw 600 uppercase ls 0.06em var(--text-secondary)`) beneath/above a high-contrast value. Decouple `<h1>–<h3>` semantics from visual size.
- **Action Hierarchy**: (1) *Primary* (1 per view, solid fill), (2) *Secondary* (subtle fill or `1px` outline), (3) *Tertiary* (ghost/text), (4) *Destructive* (quiet secondary/ghost in main view; bold crimson red strictly inside confirmation modal).

## 3. Layout & Spacing
- **Start with Generous Whitespace**: Begin with `py-24` to `py-32` and `gap-12`, tightening only if needed.
- **Geometric Spacing Scale**: `4px` (icon-label) | `8px` (compact tags/buttons) | `12px` (input/list pad) | `16px` (card pad/gap) | `24px` (form group/card gap) | `32px` (module gap) | `48px` (tablet section) | `64px` (desktop section) | `96–128px` (hero/footer).
- **Intrinsic Max-Widths & Independent Scaling**: Constrain auth forms to `420px`, prose to `65ch`, dashboards to `1280–1400px`. Keep buttons `36–44px` tall across viewports while scaling `H1` (`64px` desktop $\rightarrow$ `32px` mobile).

## 4. Designing Text & Typography
- **10-Step Type Scale**: `12px` (badges/footnotes) | `14px` (labels/tables/controls) | `16px` (body/inputs) | `18px` (lead/card titles) | `20px` (subheaders) | `24px` (modal/card headers) | `30px` (`H2`) | `36px` (`H1` app) | `48px` (hero) | `60px+` (display). Use `rem`/`px` or `clamp(2rem, 5vw, 4rem)` (never nested `em`).
- **Line Length & Baseline Alignment**: Constrain prose to **`45ch–75ch` (`max-w-[65ch]`)**. Align mixed sizes (`$49` + `/ mo`) with `align-items: baseline` (never `center`).
- **Inverse Leading & Size-Specific Tracking**:
  - Headlines (`24px+`): Tight leading (`1.0–1.15`), negative tracking (`-0.02em` to `-0.04em`), `font-optical-sizing: auto`.
  - Body (`14–18px`): Relaxed leading (`1.5–1.65`), `0` tracking.
  - Uppercase Labels: Expanded tracking (`0.08em–0.15em`), `line-height: 1.0` on badges/buttons.
- **Alignment Law**: Left-align prose. Strictly **right-align numeric, currency, date, and percentage columns** (`text-align: right; font-variant-numeric: tabular-nums`) with matching right-aligned table headers.

## 5. Working With Color
- **HSL / OKLCH Ramps & Hue-Shifting**: Build 8–10 shade ramps (`50–950`). Shift Hue toward warm **Yellow** when lightening and toward cool **Blue/Indigo** when darkening.
- **No Dead Neutral Grays (`s: 0%`)**: Tint grays with `2–5%` warm stone (editorial/hospitality/luxury) or `4–8%` cool slate (SaaS/fintech/devtools).
- **The "Flip" Badge Technique**: Pair a soft tinted background (`bg-emerald-500/10` or `#ecfdf5`) with rich hue text (`#065f46` light / `#34d399` dark) and a `1px` border. Always pair color with an icon or text label for color-blind accessibility.

## 6. Depth, Elevation & Translucent Materials
- **Overhead Light Simulation**: Raised surfaces catch light on top (`border-t border-white/15` or `inset 0 1px 0 rgba(255,255,255,0.12)`) and cast shadows below. Recessed wells (inputs/toggles) use top inner shadows (`inset 0 2px 4px rgba(0,0,0,0.08)`).
- **5-Level Dual-Shadow System** (1 crisp direct + 1 diffused ambient):
  ```css
  --shadow-sm:  0 1px 2px rgba(0,0,0,0.05);
  --shadow-md:  0 4px 6px -1px rgba(0,0,0,0.08), 0 2px 4px -2px rgba(0,0,0,0.05);
  --shadow-lg:  0 10px 15px -3px rgba(0,0,0,0.10), 0 4px 6px -4px rgba(0,0,0,0.05);
  --shadow-xl:  0 20px 25px -5px rgba(0,0,0,0.15), 0 8px 10px -6px rgba(0,0,0,0.05);
  --shadow-2xl: 0 25px 50px -12px rgba(0,0,0,0.25);
  ```
- **Dark Mode Elevation & Apple Translucency**: Closer to viewer = lighter surface (`#08090a` canvas $\rightarrow$ `#101114` card $\rightarrow$ `#181a1f` modal) + `1px solid rgba(255,255,255,0.08)`. For floating chrome, use `backdrop-filter: blur(20px) saturate(180%)`; never stack two light translucent surfaces; honor `@media (prefers-reduced-transparency: reduce)` and `prefers-contrast: more`.

## 7. Images, Finishing Touches & Component Playbook
- **Images**: Protect text over photos via dark scrim (`rgba(0,0,0,0.55)`), bottom gradient scrim, grayscale multiply, or subtle `text-shadow`. Prevent image bleed with `box-shadow: inset 0 0 0 1px rgba(0,0,0,0.08)`. Never upscale `16px` icons (enclose inside a `40–48px` badge); crop dashboard screenshots at 100% scale; lock user photos with `object-fit: cover`.
- **Finishing Touches**: Replace noisy borders with surface shifts, shadows, or `24–32px` gaps; add `3–4px` top/left accent borders (`border-t-4`); use custom SVG checkmarks, clickable **Selection Cards** instead of radio circles, and **First-Class Empty States** (icon + headline + benefit + primary CTA).
- **Component Rules**:
  1. *Forms*: Static label above input (`mb-1.5 12px fw 600`); input `h 40px pad 8px 12px 14px radius 6–8px` with `3px` focus ring; **Nested Input-Button** (`pad 4px radius 10px` wrapper); Switch = instant live action vs. Checkbox = submitted form.
  2. *Tables*: Zero vertical borders, `14px 16px` cell pad (`36–44px` dense), subtle row hover (`rgba(128,128,128,0.04)`), `11px uppercase ls 0.06em` headers.
  3. *Buttons*: Horizontal pad = `2×` vertical (`6px 12px` sm, `8px 16px` base, `12px 24px` lg), `:active` `scale(0.98)`, disabled `opacity: 0.4`.
  4. *Modals & Dropdowns*: Scrim `rgba(0,0,0,0.6) blur(4px)`, offset `translateY(-8%)`, 3 escape hatches (`✕`, `Escape`, backdrop click); isolate destructive dropdown items at bottom.

# 02 — Usability & Ergonomics Engineering: Don't Make Me Think (Steve Krug)

1. **Krug's 3 Laws**: (1) **Don't Make Me Think** (every view must be self-evident), (2) **Mindless Clicks Over Puzzling Clicks** (5 unambiguous clicks with strong **Information Scent** beat 2 hesitant clicks), (3) **Omit Needless Words** (cut 50% of prose, ban "Happy Talk" and form instructions).
2. **How Users Behave**: Users **scan** at 100 km/h (fixating on keywords/CTAs), **satisfice** (pick the first reasonable option), and **muddle through** (rely on conventions, never manuals).
3. **Billboard Design for Scanners**:
   - Place logo top-left, primary nav top/left, search in header, utilities top-right.
   - Mirror logical hierarchy visually; never style static headings in link color; ban "Mystery Meat" hover-only discovery.
   - **Proximity Law of Headings**: Keep headings closer to the paragraph they introduce than the preceding block (`margin-top: 32px; margin-bottom: 8px`). Keep inline help brief, timely, and adjacent.
4. **Navigation, Information Scent & The Trunk Test**:
   - **Checkout / Onboarding Exception**: Strip global navigation during multi-step checkouts/registrations; keep only Logo, `"Back to Cart"`, and `Step 2 of 3`.
   - **Information Scent Law**: Destination `H1` MUST match the exact wording of the link clicked.
   - **The Trunk Test (5s Diagnostic)**: On any interior view, a user must instantly spot: (1) Site ID, (2) Page `H1`, (3) Major Sections, (4) Local Options, (5) "You Are Here" indicator/breadcrumbs, (6) Search.
5. **Homepage, Goodwill & Mobile Ergonomics**:
   - Answer in 5s: *What is this? What can I do here? Why choose this? Where do I start?* Use a specific `6–8` word tagline.
   - Preserve Goodwill: Show upfront pricing, auto-format inputs, preserve form state across errors, provide 1-click Undo.
   - Mobile & A11y: Enforce **`44×44px`** touch targets, zero hover dependencies (`No cursor = no hover = no clue`), HTML5 `type="email|tel"` / `inputmode="numeric"`, meaningful `alt` (`alt=""` decorative), semantic `<button>/<a>/<label>`, and `focus-visible:ring-2`.

# 03 — Universal Layout Principles & Swiss Grid Systems (Beth Tondreau)

1. **Content Dictates the Grid (6 Grid Families)**:
   - *Single-Column (Manuscript)*: Essays/docs/legal (`max-width: 65ch / 680px`, generous margins, *Crystal Goblet* clarity).
   - *Two-Column*: Symmetrical `50/50` (comparisons, split heroes) or Asymmetrical Golden Ratio `2:1` (`67/33` narrative + sticky summary separated by a `1px` hairline).
   - *Three-Column Editorial*: **The "Hang Line" Technique** (drop column tops to a shared horizontal hang line below the headline; vary image aspect ratios).
   - *Multi-Column & Khoi Vinh's Law of 12*: Build master grids in **12 columns** (divisible by `1, 2, 3, 4, 6, 12`), spanning `8+4`, `6+6`, `4+4+4`, or `3×4`.
   - *Modular & Bento Matrices*: Columns $\times$ rows. **Empty Module Law**: leave strategic empty cells as rest zones; mix tall, wide, and square modules.
   - *Hierarchical / Banded Strata*: Full-width horizontal conversion bands (`Navbar -> Hero -> Monochrome Logo Ticker -> Bento -> Metric Proof -> Pricing -> Footer`).
2. **Typographic & Chromatic Grid Structure**:
   - Exhaust 1 versatile typeface (Roman, *Italic*, **Bold**, `ALL-CAPS 0.1em`) before adding a 2nd/3rd.
   - Break pull quotes across gutters; use `90deg` vertical headers (`writing-mode: vertical-rl`) as structural pillars.
   - Avoid "Grid Cages" (use sparse horizontal hairlines and proportional bars `↑ 14.2%`). Around vibrant photos, keep UI chrome strictly monochrome.
3. **Swiss Graphic Grid & Z-Axis Interruptions**:
   - **Karl Gerstner's "Program" & 4px/8px Baseline Lock**: Lock every font size, `line-height`, padding, and margin to `4px`/`8px` multiples so adjacent columns align horizontally. Use `1px` hairlines as spatial framing and extreme scale contrast (`64px fw 400` vs `11px fw 600`).
   - **5 Z-Planes**: `Z-0` Canvas $\rightarrow$ `Z-10` Cards/Rules $\rightarrow$ `Z-20` Breakout overlaps (`-mt-8`) $\rightarrow$ `Z-30` Sticky nav/dropdowns $\rightarrow$ `Z-50` Modals.
   - **Cutout Silhouettes & Controlled Surprise (80/20 Rule)**: Let background-removed hardware/human silhouettes cross card borders; keep 80% strict grid order, then introduce **1 intentional grid interruption**. Place diagrams/code immediately adjacent to the text referencing them.

# 04 — Visual Identity, Ortho-Typography, IA & IHM Ergonomics

1. **Chromatic Spatiality & Anti-Halation**:
   - **Warm Colors (Red, Orange, Yellow)** optically **advance** (use for urgent CTAs/alerts); **Cool Colors (Blue, Slate, Green)** optically **recede** (use for calm backgrounds/containers).
   - **5-Color Swatch & Anti-Halation Rule**: `1 Primary + 1 Secondary + 1 Accent + 1 Light Neutral + 1 Dark Neutral`. Avoid pure `#000` ink on pure `#FFF` (`21:1` halation glare); use `#111827` / `#141413` on `#f8fafc` / `#faf9f5`.
2. **Vox-ATypI & 5 Ortho-Typography Laws**:
   - *Classifications*: Humanes/Garaldes (Garamond, Caslon), Réales (Baskerville, Imperial), Didones (Bodoni, Didot — display only), Mécanes (Slab), Linéales (Geist, Suisse, Scto Grotesk), Incises (Optima/Zapf).
   - *5 Laws*: (1) Never stretch fonts (`scaleX`), (2) Max 3 families (`1 Display + 1 Body + 1 Mono`), (3) Verify multilingual diacritics (`é, è, ê, à, ç, œ, ß, ñ`), (4) Never hyphenate proper nouns, brand names, prices, or dates, (5) French double punctuation (`: ; ? !`) requires a non-breaking thin space before (`Bonjour\u00A0!`, `10\u00A0000\u00A0€`) and accented capitals (`À PROPOS`, `ÉCOLE`).
3. **Gaze Direction, Text/Image Ratios & IA**:
   - **Law of Human Gaze**: Orient photo subjects looking toward the Primary CTA, never off the viewport edge.
   - **Ratios**: `80% Image / 20% Text` (Luxury/Travel/Fashion), `50/50` (SaaS/Hardware), `80% Text / 20% Image` (Fintech/Legal/Docs).
   - **3 IA Structures**: *Tree* (`Home -> Category -> Sub-page`), *Persona Routing* (*Individuals vs Enterprise*), *Linear Funnel* (`Hook -> Problem -> Solution -> Proof -> Pricing -> Checkout`). Match URL slugs to `H1` and add a sticky `#section` TOC on `1,500+` word pages.
4. **IHM Ergonomics, Banner Blindness & Neuro-Safety**:
   - Start CTAs with imperative verbs; expand acronyms on first use; never create a 1-item `<ul>` list.
   - **Zero-Click Hero Rule**: Expose interactive utility (search, prompt input, calculator, sandbox) directly on the Hero.
   - **Prevent Banner Blindness**: **NEVER continuously animate the brand logo or top header**. Ban watermarks under prose (`30%+` reading slowdown). Place `<figcaption>` under proof images.
   - **WCAG 2.3.1 Neuro-Safety**: Strictly ban flashing/blinking `> 3 times/second` (`>3Hz`).

# 05 — Laws of UX, Cognitive Load & Ethical Choice Architecture

1. **The 10 Core Laws of UX**:
   - **Jakob's Law**: Preserve familiar conventions so mental energy goes to the task.
   - **Fitts's Law**: $\text{ID} = \log_2(2D / W)$. Minimum `44×44px` touch (`32×32px` desktop), pad `16px` icon hitboxes, keep `16–24px` dead-space between `Save` and `Delete`, use bottom mobile thumb zone and desktop screen edges.
   - **Hick's Law**: $\text{RT} = a + b \log_2(n)$. Limit conversion points to 1 Primary CTA + max 1–2 secondary options; highlight 1 "Recommended" tier.
   - **Miller's Law & Chunking**: Working memory holds `4` active visual chunks. Group nav/cards into `3–4` items; auto-chunk strings (`4444 4444`, `+1 (555) 234-5678`, `123-456`).
   - **Postel's Law**: Accept flexible human input (spaces/dashes in phones/cards, `trim()`, 6-digit OTP paste into box 1) and normalize in software.
   - **Peak–End Rule**: Polish the core value moment and completion summary; turn 404/network drops into wins via `localStorage` draft recovery.
   - **Aesthetic–Usability Effect**: Polish builds trust, but measure task completion independently during testing.
   - **Von Restorff Effect**: Restrict high-chroma accents to **`10%` of the viewport** so primary CTAs stand out.
   - **Tesler's Law**: Absorb complexity in code (infer city from ZIP, auto-detect card brand from BIN).
   - **Doherty Threshold (`< 400ms`)**: `0–100ms` instant (`pointerdown`), `100–400ms` flow transitions (`150–240ms`), `400–1,000ms` layout-matched **Skeleton Screen**, `1–10s` optimistic UI/determinate progress, `>10s` background task + toast.
   - *Supplementary*: *Prägnanz* (simple geometry), *Serial Position* (`Home` first, `CTA/Profile` last), *Zeigarnik* (`Step 2 of 4` rings), *Pareto 80/20*.
2. **Cognitive Load Theory**: $\text{Total} = \text{Intrinsic} (\text{segment steps}) + \text{Extraneous} (\text{drive to } 0) + \text{Germane} (\text{maximize})$. Eliminate **Split-Attention** (place labels/errors directly on data, never in distant legends) and **Redundancy**.
3. **CNIL Ethical Choice Architecture & Apple's 8 Principles**:
   - **Ban 7 Dark Patterns**: Visual Misdirection (bright Accept vs hidden Reject), Preselection (pre-checked add-ons), Roach Motel (1-click signup / phone cancel), Nagging, Sneaking hidden fees, Confirmshaming, and unpaginated Infinite Scroll traps.
   - **Desirable Friction**: Add conscious System 2 confirmation friction strictly for irreversible destructive actions; give `Accept` and `Refuse` equal visual weight.
   - **Apple's 8 Principles (WWDC 2026)**: *Purpose, Agency, Responsibility, Familiarity, Flexibility, Simplicity (not minimalism), Craft, Delight*.

# 06 — Motion Design Systems & Apple Fluid Interfaces

1. **Productive vs. Expressive Motion & Duration Tokens**:
   - **Productive (`70–240ms`, zero bounce)**: Dropdowns, tabs, tooltips, sorting, hover, inline validation.
   - **Expressive (`250–600ms`, choreographed)**: Hero reveals, onboarding, full-view transitions. Faster on mobile (`200–250ms`) than desktop (`250–350ms`). Never exceed `400ms` on utility UI.
   - Tokens: `--duration-instant: 70ms` | `--duration-fast: 120ms` | `--duration-normal: 180ms` | `--duration-moderate: 240ms` | `--duration-slow: 320ms` | `--duration-slower: 450ms`.
2. **Custom Cubic-Beziers & Choreography (Never `transition: all` or `linear`)**:
   - **Ease-Out (Entrances/Hover)**: `cubic-bezier(0.16, 1, 0.3, 1)` (Expo Out) or Apple Sheet `cubic-bezier(0.32, 0.72, 0, 1)`.
   - **Ease-In (Exits — `20–30%` faster than entrances)**: `cubic-bezier(0.4, 0, 1, 1)`.
   - **Ease-In-Out (On-screen reflow)**: `cubic-bezier(0.4, 0, 0.2, 1)`. **Overshoot**: `cubic-bezier(0.34, 1.56, 0.64, 1)`.
   - Enter and exit along the exact same vector; anchor popovers to triggers (`transform-origin`); overlap staggered list reveals by **`30–50ms`** (`< 500ms` total cap).
3. **Apple Fluid Interfaces: Springs, 1:1 Tracking & Momentum Projection**:
   - **Respond on `pointerdown`**: `transform: scale(0.97); transition: transform 100ms ease-out`. Track drags 1:1 via `el.setPointerCapture(e.pointerId)` preserving `grabOffset = e.clientY - el.getBoundingClientRect().top` (`~10px` hysteresis).
   - **Interruptibility**: Never lock input during transitions; always animate from the live on-screen presentation transform; blend velocity across reversals using independent X/Y springs.
   - **Spring Parameters**: Default **`Damping: 1.0, Response: 0.3–0.4s`** (critically damped, zero bounce `{ type: 'spring', bounce: 0, duration: 0.4 }` for 90% of UI). Use **`Damping: 0.8`** (`bounce: 0.2`) **ONLY** when the gesture carried physical momentum (flick/throw).
   - **Velocity Handoff, Momentum Projection & Rubber-Banding**:
     ```js
     // Project resting endpoint (d ≈ 0.998 normal scroll | 0.99 snappy sheet)
     const project = (v, d = 0.998) => ((v / 1000) * d) / (1 - d);
     const target = nearestSnapPoint(currentPos + project(releaseVelocity));
     // Progressive boundary resistance
     const rubberband = (over, dim, c = 0.55) => (over * dim * c) / (dim + c * Math.abs(over));
     ```
   - Fire visual, audio, and haptic feedback on the **exact same frame**.
4. **Compositor Performance & Accessibility**: Animate strictly **`transform`** and **`opacity`** (pre-render hover shadows on `::after` and transition `opacity`). Honor `@media (prefers-reduced-motion: reduce)` by replacing slides/springs with `120–200ms` opacity cross-fades.

# 07 — Atomic Design & 3-Tier Token Architecture (Brad Frost)

1. **5 Concurrent Stages**: `Atoms` (indivisible primitives; **mandatory `margin: 0`**, parent controls `gap`) $\rightarrow$ `Molecules` (single-responsibility groups: Search Form, Stat Metric) $\rightarrow$ `Organisms` (self-contained regions: Header, Hero, Pricing Matrix, Bento Grid) $\rightarrow$ `Templates` (structural skeletons) $\rightarrow$ `Pages` (stress-tested with real/worst-case content).
2. **3-Tier Design Tokens**:
   - *Tier 1 Primitive*: Raw context-agnostic values (`--color-slate-900: #0f172a; --space-4: 16px`).
   - *Tier 2 Semantic*: Role-based intent switching across Light/Dark (`--surface-primary: var(--color-slate-900); --border-hairline: rgba(255,255,255,0.08)`).
   - *Tier 3 Component*: Scoped overrides (`--btn-primary-bg: var(--accent-interactive)`).
3. **Governance**: Escalation path: Use existing component as-is $\rightarrow$ Configure via props/variants $\rightarrow$ Upgrade shared component (never copy-paste one-off forks).

# 08 — Modern UI Design Patterns & Generative AI / Agentic UX

1. **Core UI Patterns**:
   - *Cards*: Max `3–4` data points per card; stretched clickable area.
   - *Accordions*: For FAQs/filters; never hide primary sequential reading.
   - *Tabs*: `2–5` peer views, `1–2` word labels on 1 row, preserve state.
   - *Breadcrumbs*: Above `H1` for `3+` levels (`/` or `›`).
   - *Mega-Menus*: Use a **safe diagonal cursor triangle** (`150ms` hover intent delay).
   - *Mobile Navigation*: Top `3–5` destinations in a persistent **Bottom Tab Bar** (thumb zone); secondary links in Drawer.
   - *Pagination*: **Numbered Pagination** for dashboards/search/B2B catalogs; **"Load More"** for media galleries.
2. **Generative AI & Agentic UX (BCG X / Microsoft HAX)**:
   - **Prompt Scaffolding**: Solve the blank-canvas problem with `3–4` clickable starter prompt chips and `/slash` or `@context` pills.
   - **Hybrid Generative UI**: Embed deterministic interactive widgets (sliders, sortable tables, date pickers, selection cards) inline inside conversational streams + direct canvas click-to-refine.
   - **Verifiable Trust**: Attach inline hover citations (`[1]`, `[2]`) opening source preview cards at the exact passage; distinguish deterministic DB lookups from probabilistic synthesis.
   - **Agent Execution Traces & Approval Gates**: Show collapsible step-by-step status accordions, a persistent **Stop / Pause** button, and a mandatory **Review & Approve Card** before external/destructive mutations. Maintain stable streaming heights without hijacking manual upward scroll.

# 09 — Playbook Anti-Slop, High-Agency Dials & Vanguard UI Architecture

1. **Global Calibration Dials (`8, 6, 4`) & Creative Variance Engine**:
   - **`DESIGN_VARIANCE: 8`**: Ban centered Heroes when `> 4`; force fractional grids (`2fr 1fr 1fr`), Split-Screen 50/50, or Asymmetric Bento.
   - **`MOTION_INTENSITY: 6`**: Custom cubic-beziers, springs (`damping: 1.0`), magnetic `useMotionValue` / `useTransform` (never `useState` on continuous motion).
   - **`VISUAL_DENSITY: 4`**: Macro-whitespace `py-24` to `py-40`. When **`VISUAL_DENSITY > 7` (Cockpit Mode)**: ban generic card boxes; group data via `1px` hairlines (`border-t, divide-y`), negative space, and mandatory `font-mono` (`tabular-nums`) on all numbers.
   - **Pick 1 Vibe Archetype**: (1) *Ethereal Glass* (`#050505 / #08090a`, `border-white/10`, `Geist / Satoshi`), (2) *Editorial Luxury* (`#FDFBF7 / #faf9f5`, `PP Editorial New / Instrument Serif / Newsreader`, fixed film grain `opacity-[0.03]`), or (3) *Soft Structuralism* (`#f4f4f2 / #fff`, `Clash Display / Cabinet Grotesk`, multi-layer ambient shadows).
   - **Pick 1 Layout Archetype + Strict `< 768px` Collapse**: (1) *Asymmetrical Bento* (`col-span-8` + `col-span-4`), (2) *Z-Axis Cascade* (`-2deg / 3deg` desktop rotation reset to `0deg` on mobile), or (3) *Editorial Split* (`w-1/2` left type + right interactive cards). **Universal Mobile Rule**: collapse to 1 column (`grid-cols-1 w-full px-4 py-8 gap-6`) below `768px`.
2. **Haptic Component Craft & Fluid Choreography**:
   - **Double-Bezel (Doppelrand) Nested Architecture**: Outer Shell (`bg-black/5` or `bg-white/5`, `border-white/10`, `p-1.5` or `p-2`, `rounded-[2rem]`) + Inner Core (distinct surface, top specular highlight `shadow-[inset_0_1px_1px_rgba(255,255,255,0.15)]`, **concentric inner radius** $R_{\text{inner}} = R_{\text{outer}} - \text{padding}$, e.g. `rounded-[calc(2rem-0.375rem)]`).
